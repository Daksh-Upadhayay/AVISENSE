# engine-failure-detection- Using sensory data and other measurements 
 This project focuses on developing a machine learning–based system to predict potential aircraft engine failures before flight takeoff. Using the NASA N-CMAPSS turbofan engine dataset, which provides detailed core engine performance parameters, thermal and pressure health indicators, and operational conditions, the model classifies whether an engine is healthy or at risk of failure. The system aims to improve flight safety, maintenance efficiency, and predictive diagnostics by leveraging advanced data-driven techniques such as time-series analysis, feature engineering, and classification algorithms. The model is evaluated on unseen data to ensure robustness, accuracy, precision, and recall, minimizing false alarms and avoiding overfitting.
